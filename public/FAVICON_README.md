# Favicons pour Google Search

## Fichiers requis pour que le logo apparaisse dans Google :

1. **logo-16.png** - 16x16px (petit favicon)
2. **logo-32.png** - 32x32px (favicon standard)
3. **logo-180.png** - 180x180px (Apple Touch Icon)
4. **logo-192.png** - 192x192px (Android)
5. **logo-512.png** - 512x512px (Android large)

## Spécifications :
- **Format** : PNG
- **Fond** : Transparent ou noir (#000000)
- **Logo** : Blanc (#FFFFFF) ou or (#D4AF37)
- **Style** : Simple et lisible à petite taille

## Génération rapide :
Vous pouvez créer ces fichiers à partir de votre logo.svg en utilisant :
- Un outil en ligne : https://realfavicongenerator.net/
- Ou redimensionner votre logo-og.png aux bonnes tailles

## Note importante :
Google peut prendre **plusieurs jours à plusieurs semaines** pour mettre à jour les résultats de recherche. Pour accélérer :
1. Utilisez Google Search Console
2. Demandez une nouvelle indexation de la page d'accueil
3. Attendez 1-7 jours
