# Logo pour les résultats de recherche (Open Graph)

## Fichier requis :
- `logo-og.png` - Logo Nexus Circle blanc sur fond noir

## Spécifications :
- **Format** : PNG
- **Dimensions** : 1200x630px (ratio 1.91:1)
- **Fond** : Noir (#000000)
- **Logo** : Blanc (#FFFFFF)
- **Poids max** : 1MB
- **Transparence** : Non nécessaire (fond noir opaque)

## Utilisation :
Ce logo apparaît dans :
- Les résultats de recherche Google
- Les aperçus de partage sur les réseaux sociaux (Facebook, LinkedIn, Twitter)
- Les cartes de site dans les résultats de recherche

## Note :
Si vous n'avez pas encore ce fichier, vous pouvez :
1. Créer une image 1200x630px avec fond noir
2. Y placer le logo Nexus Circle en blanc au centre
3. Sauvegarder en PNG dans le dossier `public/`

Le logo doit être bien visible et lisible sur fond noir.
